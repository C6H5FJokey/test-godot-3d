# 设计文档 —— 潜行暗杀（暂名）

参考坐标：**耻辱的系统密度**（潜行/暗杀/法术/盗窃/警戒传播）+ **只狼的近战交互**（格挡/弹反/失衡/处决）。
目标不是复刻剧情，剧情只是给玩家一个由头。

本文档只写"规则"，不写实现。所有数值都是**默认值 + 手感旋钮**，全部可在编辑器里调。

## 0. 已锁定的前提

| # | 决策 | 结论 |

| 1 | 视角 | **第一人称**（现状已是，保持） |
| 2 | 多人 | **合作 PvE，2 人**，留到最后做，但三条纪律从现在起就守 |
| 3 | 失败模型 | **检查点**（不整关重载、不做手动存档） |

**从第 2 条衍生、现在就要守的三条纪律**（现在不做任何额外工作，只是不给自己挖坑）：
1. 角色状态只在服务端算，客户端只发输入。
2. 输入永远走 `Intent`，任何地方都不直接改位置/状态。
3. 任何随机都必须能指定种子（否则联机时双方世界不一致）。

## 1. 玩家

### 1.1 相机与"自视"

- 现状：`MainCamera` 是 `Player` 的子节点，局部 `(0, 1.5, -0.3)`；yaw 转身体、pitch 转相机（±70°）。方向正确，**保留**。
- **相机位置**：保持在**稳定的枢轴**上（`Player → CameraPivot(俯仰) → MainCamera(抖动/cull_mask)`），**不挂骨骼**。
  - 原因：相机若继承头部骨骼动画，等于把躯干与头部的运动全部叠加到视角上——会破坏鼠标俯仰控制，且必然晕。"动作完全保真"与"玩家不晕"不可兼得。
  - 想要走路/落地的视角晃动，就单独做一个 ViewBob 旋钮（幅度/频率，可按速度驱动），默认幅度很小、可一键关闭。
- **第一人称下你 K 的动画仍然重要**，价值点在别处：手臂与武器（你自己看得见）、队友和敌人看到的你的全身动作。
- **自视规则**：自己看不见自己的头/帽子，但**队友和敌人必须看得见**。
  - 现在靠 `visible = false`（`character/骨架/Skeleton3D` 下有个 `Hat Layer` 被置为不可见）。这在多人下是错的——`visible = false` 对**所有相机**生效，等于队友看你也缺一块。
  - 正确做法：给头部/帽子网格单独一个**视觉层（VisualInstance3D.layers）**，自己的相机用 `cull_mask` 关掉这一层，别人的相机不受影响。
- 相机抖动（`MainCamera` 的命中抖动）与顿帧（`StopServer`）现有实现可复用，M3 接音效即可。

### 1.2 移动

| 动作 | 触发 | 默认数值 |
|---|---|---|
| 走 | 默认 | 3.0 m/s（现值） |
| 跑 | 按住 `Shift` | 5.0 m/s（现值） |
| 蹲行 | 按 `C` **切换**（再按一次站起） | 1.6 m/s；碰撞体降低到 1.1m |
| 划铲 | **跑速 > 4.0 时按 `C`** | 速度由动量衰减；**可以用移动方向微调**；**速度掉到蹲行速度以下就自动站起**；中途按 `C` 站起、按 `Space` 跳起；撞墙结束；撞敌人 → 失衡（可处决） |
| 跳跃 | 按下 `Space` **立即起跳**；**在空中继续按住就越跳越高**（马里奥式可变跳跃高度），松开即截断 | 起跳初速 v0（短跳）；`MaxJumpHold` 决定上限；松手把上升速度截断（约 ×0.5）。**跳跃不打断攻击，可以空中攻击** |
| 攀爬 | **空中贴住可攀爬面 + 按住 `W`** | 上沿高 0.8–2.5m；位移由代码插值，耗时 0.6s。落地贴着墙按 W 不触发（否则沿墙走就会被吸上去） |
| 翻越 | 跑速 > 4.0 撞向 ≤1.2m 的障碍 | 耗时 0.5s，位移由代码插值 |

**"哪里能爬"由关卡说了算**：自动探测（胸口高度向前射线 + 头顶空间检测 + 上沿高度窗口）**且**必须落在 `Climbable` 物理层上。自动探测让你不用每处摆点，白名单让墙仍然是关卡设计元素。

### 1.3 动作优先级与打断规则

这是"操作感"的宪法，AI 用同一套（所以你不用维护两套逻辑）：

| 当前动作 | 能否被主动取消 | 被击中 | 闪现 | 攀爬 | 跳跃 |
|---|---|---|---|---|---|
| 处决 / 暗杀 | 不能 | **免疫**（环境伤害仍生效） | 否 | 否 | 否 |
| 攻击 | 能 | 打断 | **打断** | **打断** | 不打断（可空中攻击） |
| 防御 | 随时 | 格挡成功则不掉血（非完美格挡有移速惩罚） | 打断 | 打断 | 不打断 |
| 划铲 | **能**（按 `C` 站起、按 `Space` 跳起；速度掉到蹲行以下自动站起） | 不打断 | 否 | 否 | 能（跳起） |
| 拾取 / 偷窃 | 能 | 打断 | 打断 | 打断 | 不打断 |
| 施法（时间扭曲） | 能 | 打断 | 打断 | 打断 | 不打断 |

### 1.4 法术

| 法术 | 类型 | 等级 1 | 等级 2 |
|---|---|---|---|
| 闪现 | 主动 | 距离 8m，耗蓝 20 | 距离 12m（**升级只提示距离**），耗蓝 20 |
| 时间扭曲 | 主动 | 敌人时间 ×0.35，持续 5s，耗蓝 60 | 敌人**暂停**，持续 4s，耗蓝 80 |
| 高跳 | 被动 | 跳跃：空中按住可越跳越高（见 1.2） | —— |

**法力池**：上限 100，自动回充上限 30（回复 3/s），药剂 +75。
（这是耻辱式设计：自动回复只够你用最便宜的法术，想连续放大招必须带药剂。）

**时间扭曲的作用域**：只对**敌人**生效，玩家与队友不受影响。多人下"全局时间暂停"不可能成立，所以这条从第一天就按"敌人局部时间"实现。

### 1.5 战斗

- **攻击时间片**：startup（前摇，不能命中）→ active（判定窗）→ recovery（后摇）。**判定窗由动画事件标记**，不由代码常量写死。
- 伤害：3–5（现值），Reach 2.0m（现值）。
- **格挡**：面朝攻击者 + 按住 `RMB` → 伤害归零，短暂移速惩罚。
- **完美格挡（弹反）**：在敌人攻击命中的**前 0.18s** 内按下格挡 → 无伤害 + 敌人进入**失衡**。

### 1.6 处决与暗杀（三种）

| 种类 | 条件 | 耗时 | 备注 |
|---|---|---|---|
| 未发现暗杀 | 敌人 `Unaware` + 你在其背后 90° 锥内 + 距离 ≤1.6m | 1.2s | 一击必杀 |
| 高空暗杀 | 你在下落中、已下坠 ≥1.5m、落点下方 1.0m 内有敌人 | 1.0s | 一击必杀 |
| 失衡处决 | 敌人处于"可处决的失衡" + 距离 ≤1.6m | 1.5s | 一击必杀 |

三种处决**全程免疫伤害**（环境伤害例外）。这意味着战斗里"打出失衡 → 处决"是最安全的动作，这是刻意的设计（弹反因此值得练）。

### 1.7 盗窃与拾取

- 地图上摆三类物品：**食物**（`use` 直接吃，回血）、**战利品**（进背包）、**消耗品**（进背包，进快捷栏）。
- **拾取一律需要按 `use`(E) + 一个手部动作**。不做自动拾取——"停下来弯腰捡"本身就是在敌人视野里暴露自己的时机，这是盗贼循环的核心张力。
- **敌人身上的物品** = 挂在敌人身上的普通 `PickableItem`。只要敌人处于 `Unaware`，就可以直接拿走，**没有迷你游戏、没有额外后果**（被发现本身就是后果）。
- 留一个 hook：物品被拿走时广播事件，脚本可以据此触发"敌人要用药时发现没了"这类事件。

## 2. 敌人

### 2.1 共享感知（所有敌人共用）

- **视觉**：视锥水平 100°、垂直 60°，视距 18m + LOS 射线（被墙挡住就看不见）；**近距 2.5m 内全向感知**。
- **听觉**：全局噪声总线，事件带"位置 + 半径"：

| 噪声源 | 半径 |
|---|---|
| 蹲行脚步 | 3m |
| 走路脚步 | 6m |
| 跑步脚步 | 11m |
| 落地 | 12m |
| 划铲 | 14m |
| 开门 | 10m |
| 撞击 | 15m |

- **光照暂时不参与计算**（需要光照采样，成本高，且不是你的需求）。

### 2.2 警戒等级（4 级）

| 等级 | 触发 | 行为 |
|---|---|---|
| `Unaware` | 默认 | 执行巡逻 / 地图事件 |
| `Suspicious` | 看见疑似目标（部分积累）或听到噪声 | 停下、转身朝来源看，短暂延迟后回岗位 |
| `Searching` | 确认异常（看到玩家一眼/听到喊叫） | 前往**黑板上的最后已知位置**搜索 12s，然后回岗位 |
| `Alerted` | 持续看到玩家 | 追击、攻击；丢失目标后回到 `Searching` |

### 2.3 警觉传播

- **每房间一个共享黑板**（最后已知位置 + 威胁等级 + 谁是目标）。
- 发现玩家的敌人**喊叫**，以 12m 为半径广播给同房间的敌人；房间外要靠声音或视线才可能接上。
- 现状（`BaseRoom` 把 3 个敌人的 `Screamed` 信号两两互连 → 一个敌人挨打全屋瞬间锁定）要拆掉。

### 2.4 行为优先级

高 → 低：**失衡/死亡 > 战斗 > 搜索 > 地图事件 > 巡逻 > 岗位待机**。
地图事件声明 `Interruptible`（默认 true）：被战斗打断后**结束后回归**原本的行为，而不是卡在事件里。

### 2.5 两种敌人

| | 近战 | 远程 |
|---|---|---|
| 生命 | 5（现值） | 4 |
| 伤害 | 3–5（现值） | 2–3 |
| 攻击 | 近身挥砍 | **有飞行时间的投射物**，有抬手预警 |
| 行为 | 追击 + 攻击 | **保持距离**；玩家靠近则后退；**不做掩体寻路** |
| 特殊 | —— | 发现玩家时**先吹哨**（传播警觉）再射击 —— 它本质上是警报器 |

### 2.6 防御与"精英"

- **防御决策**：感知到玩家攻击前摇 + `反应时间` 后按 `防御倾向` 决定是否格挡。
- 精英敌人 **= 同一套代码 + 更好的参数**，不写子类：

| 参数 | 普通 | 精英 |
|---|---|---|
| 反应时间 | 0.35s | 0.18s |
| 防御倾向 | 0.35 | 0.75 |
| 生命 | 5 | 8 |

### 2.7 失衡（唯一的状态，参数化）

**失衡和击晕是同一个状态** `Staggered`，带两个参数：`时长` + `是否可处决`。

| 来源 | 时长 | 可处决 |
|---|---|---|
| 弹反 | 2.0s | ✅ |
| 划铲撞击 | 2.0s | ✅ |
| 普通打晕（留给后续招式的接口） | 1.0s | ❌ |

## 3. 系统

### 3.1 命中反馈（"砍中的感觉"）

四件事必须同时发生：**顿帧 + 相机抖动 + 血花 + 音效**。
前三件已经实现（`StopServer` / `MainCamera` / `HitSpurt`），缺的是音效——**而音效占了"感觉"的一半以上**。所以 v1 就建音频子系统，先用占位音。

### 3.2 背包与快捷栏

- 背包两页：
  - **消耗品页**：药剂（实装）；手雷、陷阱（**只留数据和图标，不实装**）。
  - **战利品页**：经典 RPG 列表 —— 名称 / 描述 / 价值 / 数量 / 总价值，并在页脚单独显示**当前战利品总价值**。
  - 战利品页存在的意义是让玩家"心里有个数"，不是消耗品仓库。
- **快捷栏**：槽位由玩家自选（法术或消耗品），槽位数 4。
  - 快速通道：数字键 `1-4` 直接使用。
  - 慢速通道：**按住 `Tab`** 呼出转盘，鼠标/摇杆指向、松开确认；转盘呼出期间世界减速（手感旋钮，可关）。

### 3.3 经济

- 关末结算页：偷到的物品清单 + 总价值 + 击杀/被发现统计（**仅显示，无后果**）。
- 商店：法术升级、装备、消耗品。**关末界面里买**，不做关卡内的商店 NPC。

### 3.4 检查点

- 触发：进入区域自动存。
- 保存内容：玩家位置 / 生命 / 法力 / 背包 / 战利品 / **世界状态快照**（敌人死活 + 尸体位置、门的状态、已被拾取的物品）。
- 敌人**复活**（死人不复活会让关卡越玩越空，且"尸体在哪"是潜行游戏里的重要信息，值得单独存）。

### 3.5 多人（合作 2 人，最后做）

- 前提：三条纪律（见第 0 节）+ 时间法术只作用于敌人 + 处决期间的无敌在服务端裁定。
- 现在**不做任何**联机代码，只保证不违反上述前提。

**跳跃手感配方（"飘"的解法）**
先定两个数，`重力` 与 `跳跃初速` 是被它们反推出来的，不要直接调：
- `h` = 跳跃高度（**短跳**由起跳初速决定，**上限**由空中按住延长）
- `t` = 到最高点的时间（手感说了算：**0.28–0.38s 之内才不飘**）
反推公式：`重力 g = 2h / t²`，`起跳初速 v0 = 2h / t`（算的是短跳）。
参考表（g = 23.5、t≈0.32s：短跳高度 ↔ 起跳初速）：h=0.3→v0 3.76 | 0.5→4.85 | 0.6→5.31 | 1.0→6.86 | 1.2→7.51 | 1.6→8.67 | 2.0→9.70。
**"按住越跳越高"怎么给数**：按住期间**不要**沿用同一套重力——按住时用低重力（例如 `g × 0.35`）或直接给一个向上加速度；`MaxJumpHold`（典型 0.20–0.35s）决定上限。松手时把上升速度截断（约 ×0.5），就有了"短跳/长跳"的二元手感。下限 = 短跳，上限 = 按住满。
**不要用 9.8**：真实重力在游戏里必然飘。同样跳 1.2m，g=9.8 时到顶要 0.49s（滞空近 1 秒），g=23.5 时只要 0.32s（滞空 0.64s）。"重"与"轻"的感知几乎完全由 `t` 决定，不由 `g` 决定。
另外四条比调数值更管用：
1. **下落重力倍率**：`Velocity.Y < 0` 时把重力乘 1.6–2.0。治"飘"收益最大的一条。
2. **空中加速度限制**：现在 `Player.ProcessMovement()` 不分地面与空中，空中和地面一样灵敏——这会让跳跃像滑翔。空中加速度取地面的 0.3–0.5 倍。
3. **下落速度上限**：把 `Velocity.Y` 下限 clamp 到 -25 ~ -35 m/s。
4. **落地反馈**：落地时的相机下压/短暂硬直 + 落地音效（需要你 K 动画、找素材）。没有视觉与听觉反馈，物理再准也觉得飘。
最后：`* delta` 是对的——写成 `Velocity.Y -= Gravity * delta`（`Gravity` 单位 m/s²），这样改物理帧率不会改变手感。

## 5. 待你确认的默认选择

这些我按默认值写进了文档，你觉得不对就改：

1. **门**：改用**互动键 `use`(E) 开关**（之后实现），不再需要"撞开"作为踢击的替代。开门/关门会产生噪声事件（10m）。
2. **`F` 键腾空**后的用途：默认**留空待分配**（现在没有需要它的动作）。
3. **处决无敌的例外**：默认"环境伤害（掉落/陷阱）仍然生效"，其余免疫。
4. **转盘呼出时世界是否减速**：默认**减速到 30%**（不是暂停，暂停会让多人下的表现很怪）。
