# 架构决策记录（ADR）

每条 = 决策 / 理由 / 如果以后反悔怎么改。这份是你回看"我当初为什么这么定"的地方。

---

**D1 — 第一人称，不是第三人称**
理由：现状代码已经是第一人称（相机在眼睛高度），且你列的卖点在 FPP 下同样成立；改视角是净增工作量。
反悔成本：高（所有动画重做）。所以这条要确定下来。

**D2 — 用 AnimationTree 替代 AnimationPlayer**
理由：AnimationPlayer 的过渡能力不足（现状已经暴露），而 BlendSpace 能把播放速度绑到真实速度、解决脚步打滑。这也是你学 3D 的目标之一。
反悔成本：低（动画数据本身不变，只换驱动层）。

**D3 — 不用 root motion；定点动作用代码插值**
理由：root motion 会和多人权威、Jolt 物理、攀爬吸附三方打架，且让"速度"散落在几十条动画里。
反悔成本：低（定点动作的曲线是参数化的，改成 root motion 只动一处）。

**D4 — 敌人 AI 不引入行为树插件**
理由：复杂度还没到，插件会给多人同步再加一层间接。改为"FSM 执行层 + 行为优先级调度器 + 数据化策略"。
反悔成本：中（若将来 AI 数量爆炸，可把调度器换成行为树，状态类基本可复用）。

**D5 — 感知不用一个 Area3D 球，改视锥 + LOS + 噪声总线**
理由：现状是半径 5m 的球体、进范围就永久锁定（退出不清除），没有视野锥、没有遮挡、没有听觉。潜行的全部意义都建立在这套感知上。
反悔成本：低。

**D6 — 警觉传播 = 房间黑板 + 12m 喊叫广播**
理由：你的原话是"让**附近**敌人发现异常"；全关卡黑板会让潜行报废，全房间瞬间锁定则没有层次。
反悔成本：低（半径是参数）。

**D7 — 关卡 = GridMap 骨架 + Blender 特色垂直空间**
理由：GridMap 的碰撞与导航自动生成，适合规则、可复制、可攀爬的骨架；Blender 负责少数要好看、要垂直的特色空间。纯 Blender 会让关卡迭代变慢。
反悔成本：中。

**D8 — 导航改成整关一个 NavigationRegion3D**
理由：现在每房间一个，跨房间巡逻/追击会在区域边界断掉。
反悔成本：低。

**D9 — 法术资源 = 法力池，不做体力**
理由：你明确不要体力；高跳是"按久跳更高"的纯机制，不消耗资源。
反悔成本：低。

**D10 — 失败模型 = 检查点，敌人复活**
理由：整关重载会逼你把关卡做小；手动存档是纯工程量。敌人复活避免关卡越玩越空，同时单独保存尸体位置（潜行游戏里尸体位置是重要信息）。
反悔成本：低。

**D11 — 经济 = 关末结算 + 商店；战利品背包是"账本"**
理由：你要的"名称/描述/价值/数量/总价值 + 总价"只有在钱有用时才成立。背包的目的是让玩家心里有数。
反悔成本：低。

**D12 — 不做任何后果系统**
理由：你明确不要；剧情只是由头。→ **但**路线图里的关末统计页会显示击杀/被发现数（仅显示，无后果），如果你连显示都不要，删掉即可。
反悔成本：零。

**D13 — 多人 = 合作 2 人，最后做，三条纪律前移**
理由：每步都保持可联机会让开发慢 2–3 倍；但"状态只在服务端算 / 输入只走 Intent / 随机可指定种子"现在不花额外成本。
反悔成本：中（如果发现某处必须提前重构，我会在对应里程碑提出）。

**D14 — 失衡与击晕是同一个状态，参数化（时长 + 可否处决）；删除踢击，划铲接替它的"失衡来源"角色**
理由：踢一脚就能处决会让弹反系统被绕过，而弹反是你想要的交互感核心。
反悔成本：低。踢击原本能踹开门——门改用互动键开关，见 D21。

**D15 — 拾取需要按键 + 手部动作；扒窃 = 敌人身上挂的普通可拾取物，无迷你游戏、无额外后果**
理由：你的原话是"地图上会摆放"，且"被发现本身就是后果"。自动拾取会让偷窃失去节奏与风险。
反悔成本：低（扒窃的"风险判定"是可选的额外层，接口留着）。

**D16 — 快捷栏 4 槽；数字键 1-4 快速使用 + 按住 Tab 转盘**
理由：数字键对应"我知道要按什么"，转盘对应"我不确定"以及手柄场景；两者是两种认知状态，不是重复。
反悔成本：低。

**D17 — 音频子系统进 v1，先用占位音**
理由："砍中敌人的感觉"有一半以上是音效；现在项目零音频，不做的话你无法验收命中感，还会把"感觉不对"误判成动画问题。
反悔成本：零（素材你后面替换）。

**D18 — 精英 = 同一套代码 + 更好的参数，不写子类**
理由：你要的是"换皮但 AI 不一样"，那是数据问题。继承会导致类爆炸。
反悔成本：低。

**D19 — 视觉层用于第一人称自视隔离（视觉层 2 = 只对自己隐藏）**
理由：`visible = false` 会让队友也看不到你的头；视觉层才能做到"只对自己隐藏"。
反悔成本：零。

**D20 — 文档放 `docs/`（已有 `.gdignore`，Godot 不扫描）**
理由：设计/路线图/ADR/工作流四份分开，便于你单独回看。
反悔成本：零。
**D21 — 门用互动键 `use`(E) 开关，不用撞开**
理由：踢击删除后不需要再给"撞门"找替代；`use` 已经是通用交互键（拾取也在用）。开门/关门产生 10m 的噪声事件。
反悔成本：零。

**D22 — 相机放在稳定枢轴上，不挂骨骼；视角晃动是独立的可选层（ViewBob）**
理由：相机继承头部骨骼动画会把躯干与头部的运动叠加到视角上，破坏鼠标俯仰控制，且必然导致眩晕——"动作完全保真"与"玩家不晕"不可兼得。晃动必须刻意设计、幅度小、可关。
反悔成本：低（ViewBob 是独立节点层，删掉即可）。

**D23 — 蹲行是切换（不按住）；划铲是动量驱动、可微调、速度掉到蹲行以下自动站起**
理由：按住蹲会让划铲无法用移动方向微调；固定时长的划铲会和玩家的修正输入打架。划铲中途按蹲键站起、按跳跃跳起。
反悔成本：低。

**D24 — 跳跃是马里奥式可变高度（按下即起跳，空中按住越跳越高），不是起跳前蓄力**
理由：你的明确要求。参考：科尔沃按住出二段跳，道德按住越跳越高——实现后者。
反悔成本：低。

**D25 — 攀爬入口是"空中贴住可攀爬面 + 按住 W"**
理由：不需要专门按键，跳向墙面自然接上；落地贴墙按 W 不触发，避免贴着墙走就被吸上去。
反悔成本：低。
