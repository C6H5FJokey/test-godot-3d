# 增量路线图

排序原则：**风险优先 + 每一步都能按 F5 玩到**。
每个里程碑的验收标准都写成"你按 F5 之后能看到/做到什么"，不以"代码写完了"作为完成标准。

**两条轨道并行**：
- **系统轨道（我）** —— 代码与架构，下面 M0–M8。
- **关卡与美术轨道（你）** —— 关卡、动画、素材，从 M1 之后开始推进，见文末 L0–L3。

## M0 —— 动画管线与清理（P0｜我｜一天级）

**为什么排第一**：从这一步起你要真正开始 K 动画了，而动画的"驱动层"（挂在哪、谁驱动速度、判定窗谁说了算、相机跟不跟头骨骼）必须先定型——否则你 K 完第一批动画才发现要返工。下面这些改动都不碰新功能，但决定了后面每条动画的接入方式。

**交付**
1. 用 `AnimationTree` 替代 `AnimationPlayer`：`AnimationNodeStateMachine` + Locomotion 用 `BlendSpace1D`（由水平速度驱动），把播放速度绑到真实速度，消除脚步打滑与硬切。
2. 相机保持在**稳定枢轴**上（`Player → CameraPivot(俯仰) → MainCamera`），**不挂骨骼**；另加一个独立的 ViewBob 旋钮（幅度/频率/开关都是编辑器参数，默认很轻微）。
3. 第一人称自视改成**视觉层 2 + 相机 `cull_mask`**（现在靠 `visible=false`，多人下会把队友看到的你一起藏掉）。
4. 恢复武器材质的 `IsAlwaysInFront`（第一人称顺手武器的标准做法，项目里已有被注释掉的痕迹）。
5. 删除踢击：`PlayerKickState.cs`、`KickReachRaycast`、`Intent.Kick`、`"kick"` 输入动作。`restart` 已改到 `F5`；`restart` 与 `throw` 都在"可能彻底删掉"的名单里。
6. 导航从"每房间一个 `NavigationRegion3D`"改成整关一个（或用 `NavigationLink3D` 连接），否则跨房间追人/巡逻会断。

**验收（按 F5 你能看到什么）**
- 走 ↔ 跑 ↔ 停 的过渡是连续的、步子不与地面打滑（现在切换是硬切）。
- 你看不到自己的头，但从别的相机看，你和敌人的模型是完整的。
- ViewBob 能单独调大调小并一键关掉；默认轻微到几乎察觉不到（视角动效过强会晕）。
- 敌人在 Foyer 发现你之后能一路追进 Kitchen。

**素材需求**：无（用现有 10 条动画）。

## M1 —— 潜行闭环（P0｜最高风险｜我 + 你摆巡逻点）

**为什么排第一**：感知阻塞 AI、关卡、盗窃、暗杀四件事，是整棵树的命脉，也是最容易做砸的一块。

**交付**
1. `PerceptionComponent`：视锥（100°×60°）+ LOS 射线 + 视距 18m + 近距 2.5m 全向。
2. 噪声总线：脚步/跑/落地/划铲/开门/撞击，各带半径（见设计文档 2.1）。
3. 四级警戒：`Unaware / Suspicious / Searching / Alerted`。
4. 房间黑板 + 12m 喊叫广播；拆掉 `BaseRoom` 里敌人信号两两互连的旧逻辑。
5. 行为优先级调度器（失衡/死亡 > 战斗 > 搜索 > 地图事件 > 巡逻 > 待机）+ 巡逻（`Path3D`）+ 搜索 + 回岗位。
6. 玩家：蹲行（`crouch` 终于被用上）、蹲下时碰撞体降低、蹲/走/跑的噪声差异。
7. 敌人头顶的小警戒指示器（否则你没法验收，也没法调试）。

**验收**
- 你蹲着从敌人背后走过去，他不发现你。
- 你在他背后跑，他**听到**并转身去看。
- 一个敌人发现你之后，**房间里的**敌人过来（隔壁房间的不过来）。
- 你甩掉他们躲起来，他们搜索 12 秒后各自回到岗位继续巡逻。
- 你在巡逻路线上放一个"事件"（比如一个响动装置），敌人去看，看完回岗位。

**素材需求**：编辑器里摆的 `Path3D` 巡逻点（不需要美术）；可选一条脚步声占位音。

## M3 —— 战斗交互（P0｜我 + 你 K 动画）

**交付**
1. 补上**玩家受伤与死亡**路径 + 血量 HUD。
   - 已完成：受伤/死亡链路（`HealthComponent.Damaged` → `GameEvents.PlayerHurt/PlayerDied` → `PlayerHurtState`/`PlayerDyingState`）、敌人近战真正扣血、死亡界面（`DeathScreen`：Restart 重开、Exit Game 退出）、伤害来源指示器（`DamageIndicator`，屏幕外侧圆弧+箭头，3 秒内持续指向来源，来源消失后保留最后方位淡出）。
   - 受击手感：受击**不夺走操作权**（照常移动/跳跃/攻击/踢/投掷/防御），副作用是移速临时降到 `HurtSpeedMultiplier`（默认 0.5），持续 `HurtSlowDuration`（默认 0.5s），两个旋钮都在 `Player` 节点上。
   - 待做：血量 HUD（现在只有血雾 + 指示器，看不到具体血量）。
2. 敌人防御（反应时间 + 防御倾向参数）、玩家格挡、完美格挡弹反 → 敌人失衡。
3. 参数化失衡状态（时长 + 可否处决）+ 失衡处决。
4. 未发现暗杀（背后）+ 高空暗杀（下坠中）。
5. 音频子系统（总线 + 3D 播放 + 池化）接上占位音；命中反馈四件套凑齐（顿帧/抖动/血花已有）。

**验收**
- 你能和敌人对刀，能格挡，能弹反；弹反后敌人失衡，你走过去处决他。
- 你从背后靠近没发现你的敌人，一刀暗杀，不被其他人发现。
- 你从高台跳下来砸中敌人，完成高空暗杀。
- 被砍中的时候"手上有感觉"（顿帧 + 抖动 + 血花 + 音效同时发生）。

**素材需求（你 K）**：格挡、格挡受击、弹反、失衡、被处决、背后暗杀、高空暗杀、玩家受击、玩家死亡。
**素材需求（音效，你找）**：命中、格挡、弹反、暗杀、脚步、环境底噪。

## M2 —— 移动动作（P1｜我 + 你 K 动画）

**交付**
1. 定点动作框架：位移由代码在固定时长内插值（不用 root motion），时长/曲线/距离都是编辑器里的旋钮。
2. 可变高度跳跃：按下即起跳，**在空中继续按住就越跳越高**（马里奥式），松手截断；+ 滞空/落地状态与落地噪声。
3. 划铲：跑 + 蹲触发；**可用移动方向微调**；**速度掉到蹲行以下自动站起**，中途按蹲键站起、按跳跃跳起；撞敌人 → 失衡（可处决）；撞墙 → 结束。
4. 攀爬：**空中贴住可攀爬面 + 按住 `W`** 触发；自动探测 + `Climbable` 物理层白名单，上沿 0.8–2.5m。
5. 翻越：障碍 ≤1.2m 且跑速足够。

**验收**
- 你滑铲撞倒一个敌人（滑铲途中能用方向微调对准目标），然后处决他。
- 你翻过一堵矮墙不减速断档。
- 你爬上一处高台，再从上面跳下来高空暗杀。
- 轻按空格是一个小跳；跳起来之后一直按住空格，能上到你以前上不去的台子。

**素材需求（你 K）**：蹲行待机/移动、跳跃起/滞空/落地、划铲、攀爬上、翻越。（约 8 条）

## M4 —— 法术（P1｜我）

**交付**
1. 法力池 + 药剂（自动回充上限 30，药剂才到 100）。
2. 闪现（Lv1 8m / Lv2 12m）、时间扭曲（Lv1 敌人 ×0.35 / Lv2 敌人暂停；**只作用于敌人**）。
3. 快捷栏 4 槽 + 转盘（按住 `Tab`，指向选择，松开确认；呼出时世界减速 30%）；数字键 1-4 快速通道。
4. 高跳的"被动法术"标签（机制在 M2 已实现）。

**验收**
- 你闪现穿过窗户或上到高台。
- 你放时间扭曲，敌人变慢/停住，你从容走过去暗杀。
- 你按住 Tab 用转盘切法术，松开就放。

**素材需求（你 K）**：施法的空手/单手动作（闪现、时间扭曲）。**素材（你找）**：UI 图标（法术、消耗品）。

## M5 —— 盗窃 / 背包 / 经济（P2｜我）

**交付**
1. 物品数据三类：食物 / 战利品 / 消耗品（手雷、陷阱**只留数据和图标，不实装**）。
2. `use` 拾取 + 手部动作；食物即时补血；战利品入背包。
3. 背包两页：消耗品页、战利品页（名称/描述/价值/数量/总价值 + 页脚战利品总值）。
4. 敌人身上的物品（= 挂在敌人身上的 `PickableItem`）：敌人 `Unaware` 时可直接拿走，无迷你游戏、无额外后果；留"被拿走"的事件 hook。
5. 关末结算页 + 商店（法术升级、装备、消耗品）。**不做关卡内的商店 NPC。**

**验收**
- 你偷了一堆东西，关末看到清单、每行总价值和页面总价。
- 你用偷来的钱买了闪现 Lv2，下一关闪现距离变长。
- 你从睡着的敌人身上摸走了一把钥匙，他没有察觉。

**素材需求**：战利品/食物/药剂/手雷/陷阱的模型 + UI 图标。

## M6 —— 远程敌人 + 精英（P2｜我 + 你建模）

**交付**
1. 远程敌人：有飞行时间的投射物 + 抬手预警 + 保持距离 + 玩家靠近则后退；**不做掩体寻路**；发现玩家时先吹哨（传播警觉）。
2. 精英：同一套代码 + 更好的参数（反应时间、防御倾向、生命），不写子类。

**验收**
- 你在走廊被弓箭手逼着换路线（不能站着不动）。
- 你砍精英时他格挡甚至弹反你，你被反打。
- 弓箭手一吹哨，附近的人开始搜索。

**素材需求**：远程敌人的模型 + 弓/弩 + 箭矢。

## M7 —— 检查点与存档（P2｜我）

**交付**：进入区域自动存（玩家位置/生命/法力/背包/战利品），世界状态快照（敌人死活 + 尸体位置、门状态、已被拾取的物品），敌人复活。

**验收**：你死了 → 回到检查点，血/法力/偷的东西都在，被你杀掉的敌人回来了、被你打开的门还是开着的。

## M8 —— 多人合作 2 人（P3｜最后）

**前提**（现在就要守的三条纪律）：状态只在服务端算、输入只走 `Intent`、随机可指定种子。**并且在 M4 已经保证时间扭曲只作用于敌人。**

**验收**：两个人一起潜行，我在我的屏幕上看到你的动作是完整的（包括处决和攀爬），你放时间扭曲我看到敌人也变慢了。
